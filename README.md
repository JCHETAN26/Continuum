# Continuum

Real-time embedding drift detection and adaptive fine-tuning.

Every production RAG and semantic search system decays silently: the embedding model was
trained on old data, and new domains, products, and vocabulary shift the semantic space.
Continuum detects that drift automatically and adapts the model without downtime.

Scaffolding is in progress. See [`docs/brief/`](docs/brief) for the product spec and
[`docs/adr/`](docs/adr) for architecture decisions.
